# Car Dealerships Website

## A fullstack website that lists car dealerships, their ratings and reviews.

## Uses Django, ExpressJS, Flask, ReactJS, Bootstrap.

## Deployed using CI/CD Technique with a Microservices architecture.

## It has an inbuilt Sentiment Analyzer which analysis and shows sentiments of reviews in the reviews section.

## It has a login and sign up functionality

## You can also post reviews as well, after login.
